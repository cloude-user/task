## 📂 Repository Architecture

The repository is organized into three clean core directories:

```
task/
├── cloud_software_developer.md       # Complete official course syllabus (Markdown)
├── cloud_software_developer.pdf      # Complete official course syllabus (Printable PDF)
├── GIT_CHEAT_SHEET.md                 # Git version control cheat sheet

│
├── notes/                             # Theory Handbooks & Architecture PDF Guides
│   ├── module_01/                     # Programming Foundations: Python & JavaScript
│   ├── module_02/                     # AWS Certified Cloud Practitioner
│   ├── module_03/                     # AWS Associate Core Knowledge (Compute, VPC, Storage, IaC)
│   ├── module_04/                     # AWS Solutions Architect (Well-Architected, ALB, Scaling)
│   ├── module_05/                     # AWS Developer (SDK, SQS, SNS, DynamoDB, Lambda)
│   ├── module_06/                     # AWS SysOps Administrator (Monitoring, Security, Troubleshooting)
│   └── module_07/                     # AWS AI Practitioner (Bedrock, Guardrails, RAG)
│
├── lab_sheet/                         # Step-by-Step Hands-on Student Lab Guides
│   ├── module_01/                     # Python, JavaScript, and Git hands-on exercises (+ code/)
│   ├── module_02/                     # AWS Free Tier, Budget Shield, and IAM Security Labs
│   ├── module_03/                     # EC2, S3, RDS, VPC Networking, WAF, and CloudFormation Labs
│   ├── module_04/                     # Solutions Architect Hands-on Labs
│   ├── module_05/                     # Developer Hands-on Labs
│   └── module_06/                     # SysOps Hands-on Labs
│
└── projects/                          # Real-World Cloud Mini Projects
    ├── module_02_cloud_portfolio/     # Mini Project 1: Nginx & S3 Static Website Hosting
    └── module_03_cloudformation_s3/   # Mini Project 2: Hardened Enterprise S3 via CloudFormation
```
